SK PHOTOGRAPHY APP - शुरुआत के लिए

1) ZIP फाइल को कंप्यूटर में Extract करें।
2) github.com पर Free account बनाएं।
3) New repository बनाएं: sk-photography-app
4) Repository में Add file > Upload files चुनें।
5) इस फोल्डर की सभी फाइलें अपलोड करके Commit changes करें।
6) Settings > Pages > Deploy from a branch > main > /(root) > Save चुनें।
7) कुछ मिनट बाद GitHub Pages का लिंक मिलेगा।
8) Android Chrome में लिंक खोलकर Install app चुनें।
   iPhone Safari में लिंक खोलें > Share > Add to Home Screen।

ध्यान दें:
- यह शुरुआती PWA वेबसाइट ऐप है, Play Store/App Store पर प्रकाशित ऐप नहीं।
- डेमो फोटो इंटरनेट से लोड होती हैं; अपनी असली फोटो बाद में बदलें।
- WhatsApp बुकिंग नंबर 7225049168 पहले से जोड़ा गया है।
- skphotography.in डोमेन जोड़ना वैकल्पिक है और डोमेन खरीदने का खर्च अलग होगा।
